MEASUREMENT

Evaluation lab

Same task, same model, same sources. Baseline keeps full context; FreshCode sends the compressed context. Savings come only from provider-reported usage.

PAIRED · ALTERNATING
Model
Configured Bifrost model
6 model calls per task (3 paired samples)

Methodology and limits

  • Baseline: full retrieved context. Optimised: the compressed context. Same model and sources, alternating call order, 3 paired samples per task.
  • Measured: provider-reported input tokens and latency. Not compared: output tokens, answer quality, cost billing.
  • Limits: small samples, no significance test. Results are directional. Export the raw CSV from any result to check the numbers yourself.

What it saves at your scale

A cost model. The savings % is an editable assumption unless you paste a measured value.
